# E — Selected Card Generation Contract

**Trigger:** An independently derivable rule has known premises and domain of validity.

**Input:** Host-observed source assertions and source coverage, current user Goal, previously accepted matching cards, applicable original owner/constraints. Never invent source pages, digests, commit IDs, execution IDs, timestamps, cursors, measurements, or tool argv. If evidence is unavailable, return a named K or NOOP rather than guessing.

**Generate only this epistemic role:** Show the derivation and where it stops being true, not a slogan.

**Required semantic slots (use type-specific meaning, not boilerplate):**
- **premises** — source-backed and concrete; describe what changes in the engineering decision where applicable.
- **derivation** — source-backed and concrete; describe what changes in the engineering decision where applicable.
- **applicability** — source-backed and concrete; describe what changes in the engineering decision where applicable.
- **counterexample** — source-backed and concrete; describe what changes in the engineering decision where applicable.
- **implication** — source-backed and concrete; describe what changes in the engineering decision where applicable.

**Scope contribution:** Reuse a design invariant only when premises apply.

**Rejection/non-case:** Universalization from one slide, paper abstract or example.

**Conditional Soodles Outer Loop:** thinking-router first-principles or adversarial if contested. Select only after actual evidence and valid owner next are checked; mapping does not itself invoke a skill.

**Conditional Noodle Poteto/pstack:** pstack principle-model-the-domain or principle-attack-the-premise on matched observed trigger. Worker follows the already admitted playbook and has implementation freedom within its fixed contract.

**Review-writing:** Check actor, condition before required action, evidence and causal direction, proposed vs observed state, acceptance/unknown, exact technical terms, and preservation of original goal. Apply only this card's meaningful slots; do not require a `K` card to know an unavailable mechanism. Only a real P-class instruction edit triggers scoped behavior evals.

**Output:** semantic CREATE/UPDATE/REUSE/NOOP proposal, source-grounded field content, typed links with direction/counterfactual, and relevant continuation obligation. The original Host resolves stable identity and version. A valid shape is not a semantic PASS.
