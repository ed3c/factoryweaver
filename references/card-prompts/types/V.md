# V — Selected Card Generation Contract

**Trigger:** A real observation method can discriminate a named behavior.

**Input:** Host-observed source assertions and source coverage, current user Goal, previously accepted matching cards, applicable original owner/constraints. Never invent source pages, digests, commit IDs, execution IDs, timestamps, cursors, measurements, or tool argv. If evidence is unavailable, return a named K or NOOP rather than guessing.

**Generate only this epistemic role:** Separate expected from observed and actual owner receipts; honor Test Manager's smallest-sufficient scope.

**Required semantic slots (use type-specific meaning, not boilerplate):**
- **subject** — name the covered behavior/Consumer and distinguish any parent obligation outside this control.
- **oracle** — give the original observation method and decision rule, separate from the expected outcome and observed result.
- **producer** — name the actual responsible observation source; a candidate cannot issue its own acceptance receipt.
- **positive_control** — describe fixed input/preconditions and their expected discriminating output; repeating acceptance without an input is insufficient.
- **negative_control** — change a material premise and state the expected refusal/unknown/non-case result; name what it distinguishes from the positive.
- **observation_status** — report only actually observed covered results; proposed controls and missing native captures remain NOT_RUN.

**Independent parity evidence when migrating an accepted source/target:** state separate statuses for Source Identity, Consumer-observable parity, independently judged Semantic Correctness and fresh Native Consumer/Provider effect. Provide a specific matched positive input, lawful adjacent case and planted false-equivalence/changed-error-or-side-effect negative. No consumer observation = `NOT_RUN`, not zero or a PASS from same bytes/shape. Only the original Test Manager/Observer decides necessary dynamic controls, never the card writer.

**Evidence chronology:** Preserve the original prior `NOT_RUN` and the
current separately observed scoped control status as different Source/Owner
facts. A later Parser test can establish Parser PASS_SCOPED but not retroactively
rewrite earlier compiled evidence or prove Replay, Native Consumer, Trainer,
Provider effects or Parent Goal. Link current local evidence to an actually
inspected original test report; do not fill missing receipts from prose.
**Scope contribution:** Independent acceptance/effect measurement; NOT_RUN until real observation.

**Rejection/non-case:** Invented PASS, a generic rubric with no error analysis, or tests named without inputs.

**Conditional Soodles Outer Loop:** Test Manager for objective controls; installed Evals only for genuine Agent ambiguity. Select only after actual evidence and valid owner next are checked; mapping does not itself invoke a skill.

**Conditional Noodle Poteto/pstack:** pstack tdd / verification skills only on real need. Worker follows the already admitted playbook and has implementation freedom within its fixed contract.

**Review-writing:** Check actor, condition before required action, evidence and causal direction, proposed vs observed state, acceptance/unknown, exact technical terms, and preservation of original goal. Apply only this card's meaningful slots; do not require a `K` card to know an unavailable mechanism. Only a real P-class instruction edit triggers scoped behavior evals.

**Output:** semantic CREATE/UPDATE/REUSE/NOOP proposal, source-grounded field content, typed links with direction/counterfactual, and relevant continuation obligation. The original Host resolves stable identity and version. A valid shape is not a semantic PASS.
