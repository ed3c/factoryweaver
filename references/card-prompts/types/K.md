# K — Selected Card Generation Contract

**Trigger:** An actual missing input prevents a dependent decision or evaluation.

**Input:** Host-observed source assertions and source coverage, current user Goal, previously accepted matching cards, applicable original owner/constraints. Never invent source pages, digests, commit IDs, execution IDs, timestamps, cursors, measurements, or tool argv. If evidence is unavailable, return a named K or NOOP rather than guessing.

**Generate only this epistemic role:** Specify who can produce missing evidence and what other work continues; cannot demand mechanism of unknown data.

**Required semantic slots (use type-specific meaning, not boilerplate):**
- **missing_input** — source-backed and concrete; describe what changes in the engineering decision where applicable.
- **why_required** — source-backed and concrete; describe what changes in the engineering decision where applicable.
- **producer** — source-backed and concrete; describe what changes in the engineering decision where applicable.
- **affected_scope** — source-backed and concrete; describe what changes in the engineering decision where applicable.
- **next_source** — source-backed and concrete; describe what changes in the engineering decision where applicable.
- **unaffected_work** — source-backed and concrete; describe what changes in the engineering decision where applicable.

**Dynamic source uncertainty (conditional):** a static Code Intel/AST/canonical JSON analysis can locate source references but cannot prove runtime registration or downstream effects. Create or update K only when missing original dynamic Consumer/Provider observation changes an important next decision; name the actual source/owner/readback and unaffected work. Missing lexical parse capability does not force K for ordinary prose with sufficient inspected source and a legal unchanged next.

**Scope contribution:** Explicit dependency gap, not a new Issue automatically.

**Rejection/non-case:** A filler 'unknown' used to avoid checking available source or owner readback.

**Conditional Soodles Outer Loop:** source/provider owner then thinking only if real inference remains. Select only after actual evidence and valid owner next are checked; mapping does not itself invoke a skill.

**Conditional Noodle Poteto/pstack:** pstack how for code facts; figure-it-out for truly broad unknown. Worker follows the already admitted playbook and has implementation freedom within its fixed contract.

**Review-writing:** Check actor, condition before required action, evidence and causal direction, proposed vs observed state, acceptance/unknown, exact technical terms, and preservation of original goal. Apply only this card's meaningful slots; do not require a `K` card to know an unavailable mechanism. Only a real P-class instruction edit triggers scoped behavior evals.

**Output:** semantic CREATE/UPDATE/REUSE/NOOP proposal, source-grounded field content, typed links with direction/counterfactual, and relevant continuation obligation. The original Host resolves stable identity and version. A valid shape is not a semantic PASS.
