# REQ — Selected Card Generation Contract

**Trigger:** A real source requires a measurable actor outcome.

**Input:** Host-observed source assertions and source coverage, current user Goal, previously accepted matching cards, applicable original owner/constraints. Never invent source pages, digests, commit IDs, execution IDs, timestamps, cursors, measurements, or tool argv. If evidence is unavailable, return a named K or NOOP rather than guessing.

**Generate only this epistemic role:** Preserve user wording, measurable success and effort policy; do not prescribe a solution or fabricate metric baselines.

**Required semantic slots (use type-specific meaning, not boilerplate):**
- **actor** — source-backed and concrete; describe what changes in the engineering decision where applicable.
- **goal** — source-backed and concrete; describe what changes in the engineering decision where applicable.
- **measurement** — name the original observation Producer and comparison method, with population or fixed inputs where relevant; preserve missing inputs rather than repeat the desired outcome.
- **persistence** — source-backed and concrete; describe what changes in the engineering decision where applicable.
- **stop_escalation** — source-backed and concrete; describe what changes in the engineering decision where applicable.
- **acceptance** — preserve the whole required outcome and its observable conditions; a selected child atom covers only its explicitly mapped clauses.
- **non_case** — source-backed and concrete; describe what changes in the engineering decision where applicable.

**Semantic parity when an existing requirement is migrated:** preserve the original actor, Goal, full observable acceptance, forbidden/non-cases, owner and every decision-relevant source clause. A new target implementation preference is not a new Requirement. If a new user-approved behavior deliberately differs from the old REQ, preserve the before claim and record the authorized change; do not call it source-equivalent. A missing original clause remains source coverage UNKNOWN instead of silently reducing the denominator.

**Scope contribution:** Whole-task goal/acceptance anchor for one or more atoms.

**Rejection/non-case:** A reading's preferred implementation promoted to mandatory requirement.

**Conditional Soodles Outer Loop:** issue-atom; grilling only for unresolved product choice. Select only after actual evidence and valid owner next are checked; mapping does not itself invoke a skill.

**Conditional Noodle Poteto/pstack:** admitted execute/poteto-mode consumes requirement, not another selection. Worker follows the already admitted playbook and has implementation freedom within its fixed contract.

**Review-writing:** Check actor, condition before required action, evidence and causal direction, proposed vs observed state, acceptance/unknown, exact technical terms, and preservation of original goal. Apply only this card's meaningful slots; do not require a `K` card to know an unavailable mechanism. Only a real P-class instruction edit triggers scoped behavior evals.

**Output:** semantic CREATE/UPDATE/REUSE/NOOP proposal, source-grounded field content, typed links with direction/counterfactual, and relevant continuation obligation. The original Host resolves stable identity and version. A valid shape is not a semantic PASS.
