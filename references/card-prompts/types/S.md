# S — Selected Card Generation Contract

**Trigger:** One causal intervention needs a measurable strategy.

**Input:** Host-observed source assertions and source coverage, current user Goal, previously accepted matching cards, applicable original owner/constraints. Never invent source pages, digests, commit IDs, execution IDs, timestamps, cursors, measurements, or tool argv. If evidence is unavailable, return a named K or NOOP rather than guessing.

**Generate only this epistemic role:** State baseline, mechanism of expected change, effort and falsifying experiment. A plan is not evidence of effect.

**Required semantic slots (use type-specific meaning, not boilerplate):**
- **goal** — source-backed and concrete; describe what changes in the engineering decision where applicable.
- **causal_hypothesis** — source-backed and concrete; describe what changes in the engineering decision where applicable.
- **intervention** — source-backed and concrete; describe what changes in the engineering decision where applicable.
- **alternative** — source-backed and concrete; describe what changes in the engineering decision where applicable.
- **measurement** — source-backed and concrete; describe what changes in the engineering decision where applicable.
- **stop_rule** — source-backed and concrete; describe what changes in the engineering decision where applicable.

**Scope contribution:** One bounded causal experiment and later owner measurement.

**Rejection/non-case:** Multiple confounded interventions with no comparator.

**Conditional Soodles Outer Loop:** thinking-router Ablation if confounded; Test Manager chooses controls. Select only after actual evidence and valid owner next are checked; mapping does not itself invoke a skill.

**Conditional Noodle Poteto/pstack:** pstack figure-it-out for otherwise unmatched large work. Worker follows the already admitted playbook and has implementation freedom within its fixed contract.

**Review-writing:** Check actor, condition before required action, evidence and causal direction, proposed vs observed state, acceptance/unknown, exact technical terms, and preservation of original goal. Apply only this card's meaningful slots; do not require a `K` card to know an unavailable mechanism. Only a real P-class instruction edit triggers scoped behavior evals.

**Output:** semantic CREATE/UPDATE/REUSE/NOOP proposal, source-grounded field content, typed links with direction/counterfactual, and relevant continuation obligation. The original Host resolves stable identity and version. A valid shape is not a semantic PASS.
