**Compilation target:** FactoryWeaver v7.2, not a new card type or additional schema. Every label below is an *authoring semantic key*; the canonical `stable_id`, `revision` and source digests are **original Registry/CLI owned**, not generated by this document. The **full 41-card proposal library** below retains other security, runtime, cloud and unknown requirements; never treat 4 displayed slots as an exhaustive source inventory. On DRILL, update only previously accepted cards justified by new evidence; do not blindly create a duplicate G for each atom. Subject to selected Series-specific prompt registry and independent review.

## Typed-link rules

- `SPEC implements REQ`: SPEC defines the behavior needed to satisfy the *named REQ*; this does not imply code exists.
- `SPEC validated_by V`: the V card specifies independent observation, not test execution.
- `G` constraints are reused across relevant SPEC; common proximity is not `depends_on`.
- An unresolved K is a named prerequisite only for the capability it actually blocks. `X` preserves both claims plus the discriminator; it is not a PASS.
- Text link names here are descriptive **proposals**. The original FactoryWeaver preparer/Registry resolves real Card identity and refuses unknown references.
