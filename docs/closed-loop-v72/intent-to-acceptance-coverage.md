## Scope, stop, and evidence boundaries

A Task Completion Loop returns source-bound Poteto native evidence to the same supervisory Parent Goal; the separate Harness² Optimization Loop cannot self-promote its chosen final. An implementation bug under correct SPEC is a code repair, not a Card rewrite. A real source-falsified SPEC returns Card-generation feedback to the original FactoryWeaver Producer, incrementing that stable ID with before/after history and only legitimate dependency invalidation. A valid original next avoids new Thinking and produces PromptDelta NOOP. Unknown provider effects require original readback, not blind retry.

Historical card compilation DONE, native worker completion, CI PASS, a selected Harness² candidate, or a passing TLA+ design model are not whole Goal success. User intent closure requires independent original Owner/Provider evidence for all applicable original requirements. Current revision does not implement native Noodle, Harness², pstack or production activation.
