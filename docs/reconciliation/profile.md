single-valued structure and optional exact raw pin. A pin fixes bytes; it cannot
make duplicate keys unambiguous or prove original Worker provenance.

to decode with last-key-wins behavior. Main's duplicate-key refusal now covers
profiles, bindings, ordinary catalogs and pinned raw catalogs. Real CLI negative
controls refuse ambiguous data and inherited global Skill claims; positive controls
retain declared-input proof ceilings. Linked Git fixtures preserve canonical macOS
paths so the tests reach the intended Git identity and local Skill gates.

the real CLI. Whole-issue workflow selection, Worker discovery, physical isolation,
