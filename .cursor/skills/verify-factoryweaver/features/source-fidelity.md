# Independent source-to-Card semantic coverage

This feature is a source/Owner proof boundary. The FactoryWeaver CLI can name missing evidence but cannot execute native Soodles effects.

## Sub-features

- Required evidence: Actual inspected source unit, type-specific conditions, mechanism, falsifier and omission check
- Keep missing original evidence as `verified-unreachable`, never a false PASS.
- Source: references/card-classification-and-scope-assembly.md

## How to get to it (user POV)

Start from the FactoryWeaver feature map; invoke the project-local verification helper. Original Soodles Session/Host is the owner of any native continuation.

## Driving it with the CLI harness

Preconditions: Doctor ready, actually inspected source units and an independent semantic reviewer. Source/Card content review does not require Issue admission; actual native behavior remains a separate proof boundary.

- Run `python .cursor/skills/verify-factoryweaver/scripts/verify.py drive source-fidelity` from repository root.
- The helper returns the concrete unmet original Owner prerequisite without making effectful calls.
- Independently compare actual source units, per-type Card content, coverage and counterexamples under the existing E2E contract. Preserve this scoped source-review result separately from the helper's unverified output; it has no interface for scoring that review. Do not replace missing native evidence with this source ACCEPT or synthetic metadata.
- Proof: recorded CLI response, command, exit code and the retained result.json.

## Gotchas

- For a corrected Card, compare the original wrong consumer inference, the
  actual source counterexample and saved revised SPEC/V; adjusting only the
  final One-Shot text cannot repair a wrong original Card.
- For a R Card, inspect actual Entry references and whether the source backs
  their relation. Do not demand complete Scope closure in R or infer that
  based_on automatically means a runtime prerequisite.
- Source path existence does not prove semantic completeness.
- The source wave checks entrypoint presence, not semantic truth or model execution.
- A product bug belongs to the original product Owner; maintain-verification-skill cannot silently fix it.
